# 3615 UNE VIE

Jeu de simulation de vie dans le navigateur : on naît en France avec une origine tirée au hasard et on vit un tour par année, sur un écran de Minitel.

## Commandes

Node 24 (voir `.nvmrc`).

```sh
npm install       # installe les dépendances
npm run dev       # serveur de développement
npm run build     # build de production dans dist/
npm run preview   # sert le build en local
npm test          # tests Vitest
npm run lint      # ESLint + Prettier (vérification)
npm run format    # formate le code
npm run check     # vérification des types (svelte-check)
npm run perf      # banc d'essai du moteur (temps réels)
```
